# DLINATOR

first install the dependencie by running the "les insta a faire avant tout.sh"

next you can use the file fullSerie.sh (need a link like "https://anime-sama.eu/catalogue/serie-name/")

the good way to use it is :

./fullSerie.sh < yourURL > 

# 1epdl.js
